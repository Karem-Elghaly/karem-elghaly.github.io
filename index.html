Hotel Management System

A REST API with 79 endpoints covering reservations, pricing, billing, housekeeping and reports. A room availability engine prevents double booking under concurrent requests using transactions and row-level locking.

ASP.NET Core 9 Web API · EF Core · Paymob

A REST API with 50+ endpoints for products, cart, orders and reviews. Transactional checkout deducts stock and uses optimistic concurrency (RowVersion) to prevent overselling.

Hospital Management System

4 roles, refresh-token rotation, and object-level access control to prevent IDOR.

Menu, cart, checkout with promo codes, an order status state machine, and live order tracking with SignalR. Stripe payments use signature-verified, idempotent webhooks.

Gym Management System
